# Design System: 関数電卓

## Overview

白系の面と濃い文字を使う、854×480のネイティブRGB565バッファの左側800×480を使用する画面。式・結果の表示領域と8列×5行のボタンを分け、履歴は別画面に置く。Web/iOS/AndroidのUIではない。

## Colors

色の実値は[src/paint.rs](src/paint.rs)のRGB565定数を基準とする。frontmatterは各チャンネルを8ビットへ整数変換した表示用の値。

| トークン | RGB565 | 用途 |
| --- | --- | --- |
| BG | `0xf7bd` | 画面背景 |
| INK | `0x18e3` | 本文・フォーカス外枠 |
| MUTED | `0x4a69` | 履歴件数・空状態・初期値 |
| ACCENT | `0x1b89` | 等号・押下・履歴選択・Back・角度表示・カーソル |
| ERROR | `0xa900` | 計算エラー |
| FUNCTION | `0xe734` | 先頭14個のボタン |
| OPERATOR | `0xdedb` | その他の操作ボタン・Prev/Next |
| white | `0xffff` | 数字と小数点のボタン・表示面・アクセント上の文字 |

## Typography

ASCIIのDejaVu Sans Monoアトラスを使う。通常は1字12×26、結果は2倍の24×52で右寄せ。式は最大62字を表示し、カーソルに追従する。履歴の式は46字を超えると`...`を添える。

## Layout

座標と寸法は画面ピクセル。タイトルは(24,16)、表示面は(16,54)から768×100。ボタンは(16,164)を起点に96×62刻み、各90×56で間隔6。

履歴は(16,84)から768×66の行を72刻みで5件表示。式と角度を上段、結果を下段に置く。Prev/Next/Backは上部の118×42の矩形。

## Elevation & Depth

影やアニメーションはない。背景色と選択色、フォーカス枠で状態を区別する。

## Shapes

すべて角丸のない矩形。ボタンのフォーカスは濃色2ピクセルと白2ピクセルの二重枠で、アクセント色の等号にも表示する。

## Components

- 電卓ボタン：方向キーでフォーカス移動、決定で実行。初期フォーカスは`1`。タッチ開始でフォーカスと押下色を表示し、同じ場所で離すと実行する。別ボタンへの移動で押下を取り消す。
- 表示面：式の下にアクセント色の10×2カーソル。結果、初期値`0`、赤茶色のエラーと`@位置`のいずれかを表示する。
- 履歴：選択行はアクセント背景と白文字。上下で1件、PageUp/PageDownまたはPrev/Nextで5件移動する。決定または行のタップで復元し、Back/Escapeで戻る。空の場合は`No calculations`を表示する。

ホストプレビューで等号のフォーカスと履歴のタッチページ切替を確認済み。実機での表示・操作は未確認。

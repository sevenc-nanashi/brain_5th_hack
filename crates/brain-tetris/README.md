# brain-tetris

Reflexを使う第5世代Brain向けのテトリス。10×20の盤面に加え、上部に20行の非表示領域を持つ。
7-bag、5個先までのNEXT、ホールド、ゴースト、SRS、T-Spin／Mini、コンボ、Back-to-Back、全消しに対応する。

```sh
make tetris
# target/tetris/APP/Tetris/ をSDカードの APP/Tetris/ にコピー

# PCで画面をPPMに出力
make tetris-preview
```

| キー | 操作 |
| --- | --- |
| 左・右 | 左右に移動（長押し対応） |
| 上 / X | 右回転 |
| Z | 左回転 |
| 下 | ソフトドロップ |
| Space | ハードドロップ |
| C / Shift | ホールド（ブロックを固定するまで再使用不可） |
| Enter / P | 一時停止・再開 |
| Enter（ゲームオーバー時） | リトライ |
| Esc | 終了 |

## 回転・固定・入力

- SRSの各回転状態・方向に対応する5候補を順に試す。Iには専用の壁蹴り表を使う。Oは位置を変えずに回転する。
- 接地から500msで固定。移動・回転の成功で固定猶予を延長できるが、接地後の移動・回転が15回に達すると接地時に即固定する。それまでの最下段より下へ進むと回数をリセットする。失敗した操作では延長しない。
- ハードドロップは即固定。ソフトドロップで接地しても固定猶予を残す。
- 左右の長押しは初回150ms、以降40msごとに移動（DAS／ARR）。OSのキーリピートには依存しない。同時押しは後から押した方向を優先する。
- ソフトドロップは20msごと、自然落下の方が速いレベルでは自然落下と同じ間隔。
- 10行ごとにレベルアップ。自然落下はレベル1の1,000msからレベル15の7msまで加速し、以降は7msを維持する。
- 一時停止中は落下・固定猶予も停止する。出現位置が埋まるか、ブロック全体が非表示領域内で固定されるとゲームオーバー。

## T-Spinと得点

Tの最後に成功した操作が回転で、中心の斜め4隅のうち3隅以上が埋まっているとT-Spinとなる。
Tの先端側2隅が両方埋まっていれば通常のT-Spin、それ以外はMini。ただしSRSの5番目の補正で回転した場合は通常のT-Spinにする。
成功した移動・落下は回転履歴を消す。移動距離0のハードドロップや失敗した操作は履歴を消さない。

以下の基本点に、消去前のレベルを掛ける。

| 消去行数 | 通常 | T-Spin Mini | T-Spin |
| --- | ---: | ---: | ---: |
| 0 | 0 | 100 | 400 |
| 1 | 100 | 200 | 800 |
| 2 | 300 | 400 | 1,200 |
| 3 | 500 | — | 1,600 |
| 4 | 800 | — | — |

- **Back-to-Back**：TetrisまたはT-Spin／Miniのライン消去を続けると、2回目以降の基本点を1.5倍にする。消去なしでは継続し、通常の1〜3行消去で途切れる。
- **コンボ**：連続したブロックで消去すると、2回目から `50 × コンボ数 × レベル` を加算。コンボ数は2回目の消去で1、以降1ずつ増え、消去なしで0に戻る。
- **全消し**：1〜4行で800・1,200・1,600・2,000点×レベルを追加。Back-to-Back中の4行全消しは3,200点×レベルを追加する。
- **落下**：ソフトドロップは1マス1点、ハードドロップは1マス2点。レベル・Back-to-Back倍率は掛けない。

採用した得点表は[Tetris Mobileの公式ヘルプ](https://playstudios.helpshift.com/hc/en/16-tetris-mobile/faq/2437-scoring-in-tetris/?p=web)を参照。
回転・固定・T-Spinの基本ルールは[2009 Tetris Design Guidelineの公開ミラー](https://studylib.net/doc/27262492/2009-tetris-design-guideline)を参照。
タイトルによって異なる細部は上記の仕様で固定しており、ガイドライン全体への完全準拠を表明するものではない。
音声・スコア保存・対戦・180度回転は実装していない。

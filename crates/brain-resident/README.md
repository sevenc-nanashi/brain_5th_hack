# Resident

PW-H1 / V690_H1のCDTimerスロット3で動かす、小窓カウンターの実験。
Inspectorから起動する。通常の追加アプリ一覧から直接起動しない。

```sh
make inspector
```

配布物は `target/inspector/APP/Inspector/`。
`Resident.bin` を同梱したフォルダー全体をSDへコピーし、一覧 → W → Rで起動する。
`reflex build inspector` / `reflex deploy inspector ... --build` でも常駐側を先にビルドし、同梱する。

- エントリー: `0x83400000`、データ/BSS: `0x86c00000`。リンカーで各4MiBの範囲を検査する。
- 起動はSharpLib `0x84010138` のスロット3。使用中ならInspectorが中止する。
- 入口でもスロット3の起動コンテキスト `0x860430dc` を検査し、違う場合はRAMを初期化しない。
- ウィンドウID `0x2a1`、作成時フラグと状態はCDTimerに合わせる。
- カウンターは独立したPEGタイマーの通知回数。秒数ではない。
- コールバック・vtable・描画バッファはすべて常駐側に配置する。Inspectorへのポインターは持たない。
- タッチまたは破棄通知でタイマーとウィンドウを破棄し、SharpLibへこの実行パスの終了を通知する。

Inspectorの終了、他の追加アプリによる `0x90000000` の上書きから独立する構成だが、
アプリ切り替え・スリープ・再起動を含む実機動作は未検証。
純正タイマーの代わりにスロットを使う実験であり、システムへ永続的に登録しない。
表示が戻らない場合は本体を再起動する。

ABIの根拠は [アプリ起動・終了](../../docs/app-lifecycle.md) を参照。

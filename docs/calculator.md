# 関数電卓

`brain-calculator` は `no_std + alloc` と `#[reflex::main]` を使うPW-H1向けサンプル。
画面レイアウトとタッチ判定は左側800×480を基準とし、描画バッファの幅は854pxを維持する。
対象はV690_H1。通常の計算エラーは画面表示し、panicとは区別する。

```sh
make calculator
make calculator-preview
```

`target/calculator/APP/Calculator/`をSDカードの`APP/Calculator/`へコピーする。
プレビューは`target/calculator-preview/`にPPM画像を生成する。同じ出力先への再実行では上書きする。
通常画面、等号のフォーカス、履歴2ページ、エラー、panic表示をホストで描画する。
SDへのコピー、実機起動、更新ファイルの変更はビルドに含まれない。

## 操作

- タッチでボタンを押して離す。別のボタンへ移動した操作は取り消す。
- 方向キーでボタンのフォーカスを移動、決定で実行する。
- 英数字・演算記号を物理キーから直接入力できる。Backspace/Delで1文字削除。
- `<` / `>` は式のカーソル移動、`(-)` は負号挿入、`AC`は式の消去。
- `=`で計算する。決定キーは常にフォーカス中のボタンを実行する。
- `DEG` / `RAD`で角度単位を切り替える。初期値はDEG。
- `HIST`または履歴キーで履歴へ移動。上下・PageUp/PageDown、画面のPrev/Nextで選択ページを移動。
- 履歴の決定・タップで式と角度モードを復元する。Ansは最後に成功した計算結果のまま。
- Escapeは履歴から戻り、電卓画面では終了する。EXITも終了する。

## 計算規則

`f64`とlibmを使用。表示は最大12有効桁で、Ansには表示前の値を保存する。
小数の厳密計算・任意精度・複素数には対応しない。

| 項目 | 内容 |
| --- | --- |
| 演算 | `+ - * / ^`、括弧、単項符号 |
| 関数 | `sin cos tan asin acos atan sqrt ln log exp` |
| 定数 | `pi e Ans`（`ans`も可） |
| 科学表記 | `1E-3`。小文字`e`は自然対数の底 |
| 優先順位 | 累乗、単項符号、乗除算、加減算。累乗のみ右結合 |
| 省略乗算 | `2pi`、`2(3+4)`、`(2+1)3`。通常の乗算と同じ優先順位 |
| 括弧補完 | 計算時、末尾に不足する閉じ括弧だけ追加 |
| 制限 | 式512バイト、括弧・再帰解析32段、成功履歴32件 |

`-2^2 = -4`、`2^-2 = 0.25`、`2^3^2 = 512`、`6/2(1+2) = 9`。
`sin(30` は `sin(30)`として評価し、履歴にも補完後の式を保存する。
Ans未設定、ゼロ除算、定義域外、数値オーバーフロー、構文不正はエラーと位置を表示する。
`0^0`は定義域エラー。浮動小数点の丸めにより三角関数の結果などには誤差が残る。
極の検出はDEGの90度+180度の整数倍、RADの表現可能な対応値を対象とする。
履歴と入力はメモリ上だけで、終了時に破棄する。

## 実行基盤と検証

電卓は独自のPEGウィンドウ・終了処理を持たず、reflexが状態を所有する。
一括解放は正常終了時だけ行う。panicでは文字・QRを直接表示して停止し、回復は試みない。
フォントは既存Doomと同じDejaVu Sans Monoアトラスを使い、ライセンスを同梱する。

テストファイルは追加していない。一時的な自己チェックで計算の境界条件・不正入力、
入力と履歴の上限、アロケーターの整列・再確保・解放・失敗、UTF-8診断を検査する。
QRは別実装のデコーダーで描画結果から読み戻し、元の診断バイト列と比較する。
ARMビルド、ホストプレビュー、clippyに加え、実機での次の確認が必要。

- 同じキーの連続入力とPM_KEY/PM_KEY_DOWN/PM_KEY_UPの対応
- タッチ位置と800×480の操作領域のクリッピング
- 終了後の画面・フォーカス復旧、繰り返し起動時のメモリ回収
- panic画面の保持、watchdog、カメラでのQR読取

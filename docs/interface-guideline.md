# インターフェースのガイドライン

- 実際の画面サイズは800x480pxです。
  - WIDTH = 854pxは右側の電子辞書本体のUI領域を含んだサイズです。
- キー配置はこのようになっています：
  - `{}`内は（標準では）シフトキーが押されたときの動作です（キーに印字されています）
  - 1行目：「ホーム」、「国語/漢字」、「英和/和英」、（スピーカー; この部分はキーではない）、「My辞書」、「履歴」、「一覧から選ぶ」、「（電源）」
    - この行は他のキーと違って色が違います。
  - 2行目：「Q」、「W」、「E」、「R」、「T」、「Y」、「U」、「I」、「O」、「P」
    - 数字キーはありませんが、この行のキーはQから順に1~0が小さく印字されています。
  - 3行目：「A」、「S」、「D」、「F」、「G」、「H」、「J」、「K」、「L{～}」
    - 標準アプリでは`~`は複数文字のワイルドカードを意味します。
  - 4行目：「シフト」、「Z」、「X」、「C」、「V」、「B」、「N」、「M」、「ー{？}」「削除{クリア}」
    - 標準アプリでは`？`は1文字のワイルドカードを意味します。
  - 5行目：「二重上{音量+}」、「音声」、「あA1/記号」、「戻る」、「左{文字小}」、「上」、「右{文字大}」、「決定」
    - 標準アプリでは二重上はPageUpのように動作します。
    - 標準アプリでは「あA1/記号」はローマ字・アルファベット・数字の切り替えを意味します。（全角/半角キーのように動作します）
  - 6行目：「二重下{音量-}」、「音声」、「スペース/変換」、「戻る」、「左{文字小}」、「下」、「右{文字大}」、「決定」
    - 標準アプリでは二重下はPageDownのように動作します。
    - 5行目と同じキーはそのキーが2行にまたがっていることを意味します。

# Inspector

PW-H1 の画面領域と入力を確認する独立した Rust アプリ。
Reflex の PEG API を使用し、他のアプリやゲームデータは不要。

```sh
make inspector
```

`target/inspector/APP/Inspector/` を SD カードの `APP/Inspector/` にコピーする。
フォルダー内の `AppMain.bin` と空の `index.din` が必要。

## モードとロック

| キー | モード | 内容 |
| --- | --- | --- |
| ホーム | TEXT | 英大文字・数字・記号を1倍／2倍／3倍、7色、白黒反転で表示（起動時） |
| 国語/漢字 | KEYS | 押下・解放を含む直近16件のキー履歴。最新が上 |
| 英和/和英 | TOUCH | タッチ座標、押下・移動・解放、十字線 |
| My辞書 | PIXELS | タッチでカーソルを配置、方向キーで1px、Shift＋方向キーで10px移動 |

| 履歴 | SETTINGS | システムのウィンドウクリップ設定、画面矩形の確認 |

Shift **単独で1秒以上押して離す**とロック／解除する。起動時は解除状態。
ロック中はモード切替・設定変更・Esc 終了を抑止し、キー履歴・タッチ・カーソル操作は継続する。
Shift 押下中に別のキーやタッチを受け取ると、その回のロック操作を取り消す。
Shift のリピートでは計時をリセットせず、離したときに一度だけ切り替える。
Shift の修飾フラグだけでは長押し判定せず、Shift 自体の押下・解放イベントを使う。

履歴は全モードで記録し、モード切替でも保持する。切替キーや Esc も記録対象。
ピクセル座標はパネル全体の x=0〜853、y=0〜479 に制限する。
ホスト UI に隠れる位置も計測できるよう、暫定の利用可能幅800pxでは制限しない。

## ウィンドウクリップ設定

履歴キーで設定画面を開き、左で OFF、右で ON にする。初期値は ON。
起動中のみ保持し、ファイルへは保存しない。ロック中の変更は無効。

ここでのウィンドウクリップは、本体の左から右へのドラッグで発動する機能。
描画範囲を制限する PEG の `mClip` とは別物。
ON では押下・移動・解放を従来の基底ハンドラーへ渡し、OFF では Inspector 内で消費する。
どちらでも座標の計測とカーソル操作は継続する。

この方式は **実機検証待ち**。独立した許可／禁止 API は未特定。
PCConnect の `AppMain.bin` では、`0x14b24`〜`0x14b28` が種別9を消費し、
`0x14de8`〜`0x14e14` が種別10/11を自前処理して基底へ渡していない。
この処理と「PC接続では発動しない」という実機報告から、同じイベント抑止方式を採用した。
アプリへ届く前にシステムがジェスチャーを認識している場合、この設定では抑止できない。

設定画面では SCREEN API、PM/WIN REAL・CLIENT・CLIP、直近の DRAW RECT も表示する。
これらの CLIP 数値は描画用矩形で、上記スイッチの状態を表すものではない。

## 入力とピクセル計測

キー履歴の KEY/FLAGS は16進、TYPE は10進。TYPE=9/33 を押下側、34を解放側として扱う。
Shift 有効時は `00000800` → `00000840` となり、`KMOD_SHIFT = 0x40` で判定する。

タッチの押下・解放は TYPE=10/11。ドラッグは TYPE=9、KEY=`0x8000`。
データの下位16bitがX、上位16bitがYで、例の `0x01d0030e` は X=782、Y=464。
Reflex の `TOUCH_MOVE_PARAM` と `MessageData.point` を使い、ドラッグはキー履歴に入れない。
タッチ移動に合わせて座標とカーソルを更新する。緑は押下・移動、オレンジは解放。

タッチ・ピクセル画面はパネル全体854×480、50px方眼、上下の目盛りは10px刻み。
紫線は暫定の利用可能幅800pxの右端（x=799）、黄色はその中心x=400、水色はパネルの中心。
ピクセル計測の方向キーはカーソルを動かす。従来の手動境界の移動操作は廃止した。

TEXT はアプリ内蔵の5×7ドットフォントの表示テストで、本体の日本語フォントは使用しない。

## 読み取り元と制限

矩形は `(left, top) - (right, bottom)` と幅×高さで表示し、PEG の右下端は包含座標として計算する。
オブジェクト内のオフセットは REAL=`+0x0c`、CLIENT=`+0x14`、CLIP=`+0x1c`。
V690_H1 の起動規約と既存の矩形配置に基づく生値であり、これらの領域が
ホスト UI を完全に除外するかどうかは実機で比較する必要がある。

画面は PEG の Bitmap と Draw callback 経由で描画し、液晶へ直接書き込まない。
終了時にはタイマー・フォーカス・vtable を片付け、ホストへ終了を通知する。

```sh
cargo clippy -p brain-inspector --all-targets -- -D warnings
cargo clippy -p brain-inspector --features device --target armv7a-none-eabi -- -D warnings
```

実機の入力値・ホスト UI の境界・終了後の表示復旧は実機確認が必要。
